# Contact Book
A simple command-line Contact Book application developed using Python.
## Features
- Add a contact
- View all contacts
- Search for a contact
- Store contact details in a text file
## Technologies Used
- Python
- Text File Handling
## How to Run
1. Download or clone the repository.
2. Open the project folder.
3. Run
## Contact Information Stored
Each contact contains:
- Name
- Phone Number
- Email
